Features

What it actually does

Six things. Each one is a thing the in-game interface makes annoying.

bulk-moveSelect as many items as you want and move them in or out of a unit in one action.
pricingTotal value per storage unit and per inventory, shown inline. Know what's where.
multi-accountSave several Steam accounts and switch between them without logging in again.
groupingItems collapse by type into sections. Scroll a screen, not a thousand rows.
searchFilter across your whole inventory and every storage unit at once.
cross-platformWindows, macOS, Linux — one native build for each. No browser required.
